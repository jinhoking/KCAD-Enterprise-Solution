# 🏗️ KCAD Enterprise Solution

링크 : https://www.youtube.com/watch?v=Hy5RW1lY67w
본 프로젝트는 기업의 핵심 지적 재산인 도면 자산의 **보안 유출 방지**와 부서 간 효율적인 **실시간 협업 환경**을 구축하기 위해 개발된 통합 관리 솔루션입니다.

---

## 🚀 4대 핵심 솔루션 (Core Solutions)

### 👤 1. 로그인 및 직무/소속별 개인정보 관리
**"사용자의 기업 내 정체성을 정의하고 개인화된 업무 환경 구축"**
* **직무/소속별 개인화**: 마이페이지를 통해 부서(전기, 설계, 토목 등)와 직무 정보를 관리하며 시스템 전반에 실시간 반영합니다.
* **사용자 식별 최적화**: DB 조인과 `JdbcTemplate`을 활용하여 게시글 및 댓글 작성자의 소속 태그를 리스트에 정확히 출력합니다.

### 💬 2. 통합 커뮤니케이션 솔루션
**"보안과 편의성을 극대화한 사내 소통 창구 구축"**
* **1:1 보안 Q&A**: 민감한 기술 문의는 **비밀글 설정** 기능을 통해 전담 관리자와 안전한 비공개 상담 환경을 제공합니다.
* **디자인 일관성(UX)**: 공지사항 및 자유게시판의 UI를 통일하여 사용자에게 직관적이고 쾌적한 커뮤니티 경험을 제공합니다.

### 🖊️ 3. 실시간 도면 마크업 업로더 & 갤러리
**"도면 자산의 효율적인 공유와 실시간 피드백 시스템 제공"**
* **무설치 도면 뷰어/업로더**: 별도의 소프트웨어 없이 브라우저에서 직접 도면을 업로드하고 마크업(주석)을 추가하여 소통합니다.
* **시각화 갤러리 및 아카이빙**: 프로젝트별 도면을 갤러리 형태로 관리하며, 파일 첨부 상태(💾)를 직관적으로 파악할 수 있는 환경을 지원합니다.

### 🛡️ 4. 기업형 보안 권한 솔루션
**"지적 재산권 보호를 위한 사용자별 접근 권한 엄격 통제"**
* **인가된 사용자 전용 보안망**: 사내 승인된 계정만 시스템에 접근할 수 있도록 세션 기반의 보안 필터를 적용하여 정보 유출을 차단합니다.
* **관리자(Admin) 전용 관제**: 관리자 계정에 특화된 UI 배지와 전사 관리 권한을 부여하여 솔루션 운영의 안정성과 보안성을 확보했습니다.

## 🎨 솔루션 구현 특징 (Implementation Detail)
* **UI/UX 최적화**: 모든 보안 게시판 및 공유 리스트에 공통 CSS 스타일을 적용하여 기업용 소프트웨어의 전문성을 확보했습니다.
* **예외 처리 로직**: 정보가 비어있을 수 있는 관리자 계정(admin)에 대해 JSTL `choose`문을 이용한 유연한 스타일 예외 처리를 적용했습니다.
