# 🏗️ KCAD Enterprise Solution
**기업 전용 도면 마크업 및 커뮤니티 관리 통합 솔루션**

## 🖥️ 프로젝트 개요
실시간 도면 마크업 기능과 기업 구성원 간의 원활한 소통을 위한 게시판 서비스를 제공하는 웹 어플리케이션입니다. 사용자 권한별 맞춤형 UI와 효율적인 데이터 관리에 초점을 맞추어 개발되었습니다.

## ✨ 주요 기능
- **실시간 마크업**: 웹 기반 도면 뷰어 및 주석 공유 기능
- **마이페이지**: 세션 정보를 활용한 개인정보 수정 및 기업 소속(부서/직무) 정보 관리
- **통합 커뮤니티**: 
  - 공지사항 & 자유게시판: 첨부파일 및 댓글 기능
  - 고객 지원(Q&A): 비밀글 설정을 통한 1:1 문의 최적화
- **관리자 최적화**: 관리자(admin) 전용 태그 배지 및 게시글 관리 권한 부여

## 🛠️ Tech Stack
- **Backend**: Java 11, Spring Framework, Mybatis
- **Frontend**: JSP, JSTL, CSS3, JavaScript
- **Database**: Oracle / MySQL (JdbcTemplate 활용)
- **Tool**: STS (Spring Tool Suite), Git, GitHub

## 🎨 주요 구현 내용
- **UI 일관성**: 모든 게시판 리스트에 공통 CSS를 적용하여 사용자 경험(UX) 향상
- **데이터 바인딩**: DB 조인을 통해 작성자의 부서 및 직무 정보를 실시간 태그 형태로 출력
- **보안/예외 처리**: 관리자 계정에 대한 예외 스타일 적용 및 세션 기반 접근 제어
